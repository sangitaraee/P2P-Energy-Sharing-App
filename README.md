# P2P Energy Sharing App

A peer-to-peer renewable energy trading platform that allows users to buy and sell excess renewable energy securely.

## Features
- User Authentication
- Buy & Sell Energy
- Wallet System
- AI-Based Pricing
- Transaction History
- Real-time Dashboard
